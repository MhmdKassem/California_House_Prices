# House Prices

## Overview
This project goal is to predict house prices in California using the [California House Price](https://www.kaggle.com/datasets/shibumohapatra/house-price) dataset hosted on Kaggle.

## Approach
- Implement linear regression from scratch using NumPy
- Implement linear regression using scikit-learn
- Compare results between both approaches

## Dataset
- **Source:** Kaggle
- **Features:** 9 features including median income, house age, location
- **Target:** Median house value
